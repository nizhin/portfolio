Neural Network Compression for Ventricular Arrhythmia Detection

2026 · TinyML / Model Compression / Quantization

Exploring how network redesign and quantization can shrink an arrhythmia detection model for resource-constrained microcontrollers.

Optimized a deep learning model for cardiac arrhythmia detection tailored for resource constrained microcontrollers.

Compressed model size by implementing Depthwise Separable Convolutions, BatchNorm folding, and Quantization Aware Training (QAT).

Evaluated tradeoffs across INT8, INT4, and INT2 bit widths to identify the viable precision for accurate classification.
